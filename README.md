# 🚗 **Sistema de Controle de Motoristas e Rotas**  

Aplicativo desktop para gerenciamento de motoristas, rotas, pagamentos e exportação de relatórios em PDF/Excel.  

## 📋 **Funcionalidades**  
✔ **Cadastro de motoristas** (nome, idade, chave PIX)  
✔ **Registro de rotas** (data, horário, valor, forma de pagamento)  
✔ **Visualização em tabela** com filtros integrados  
✔ **Exportação para PDF e Excel**  
✔ **Filtro por mês/ano**  
✔ **Remoção de registros**  

## 🛠 **Tecnologias Utilizadas**  
- **Linguagem**: Python 3.x  
- **Interface Gráfica**: Tkinter  
- **Geração de PDF**: FPDF  
- **Manipulação de Excel**: Pandas  
- **Processamento de Imagens**: Pillow (PIL)  

## ⚙ **Pré-requisitos**  
- Python 3.8+  
- Gerenciador de pacotes `pip`
